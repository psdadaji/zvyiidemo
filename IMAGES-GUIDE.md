# Zvyii website: image guide

Saari photos `images/` folder me is naam se rakho (JPG, `<naam>.jpg`).
Photo na ho to backup photo apne aap dikhti hai, to aap ek-ek karke badal sakte ho.
File size: har photo 300 KB se kam rakho (tinypng.com se compress), taaki site fast khule.

## Logo
- `images/logo.png`: transparent PNG, **600 x 180 px** (3:1 wide) ya square ho to 400 x 400 px. Header me height 44 px par dikhega.
- `images/favicon.png`: **512 x 512 px** square.

## Influencer marketing + promotional banners (new)
| File | Recommended size | Use |
|---|---:|---|
| `images/influencer.jpg` | **1200 × 800 px** | Influencer marketing service cards and promo banner |
| `images/meta.jpg` | **1200 × 800 px** | Paid advertising / campaign imagery |
| `images/lead.jpg` | **1200 × 800 px** | Business growth / lead generation promo |
| `images/hero.jpg` | **1200 × 1440 px** | Main homepage portrait image |
| `images/home-banner-1.jpg` | **1920 × 840 px** | Optional wide desktop campaign banner |
| `images/home-banner-mobile-1.jpg` | **900 × 1200 px** | Optional mobile-specific campaign banner |

**Image count to prepare first:** 1 logo + 1 favicon + 1 hero + 1 about/team + 12 service-card images + 3 promotional images = about **19 images** for a strong launch. Reuse matching service images rather than duplicating files.

**Export rules:** JPG/WebP for photos; aim for 150–300 KB per image. Keep main subjects near the centre. Use 16:10 or 3:2 crops for cards, a 5:6 portrait for the hero, and a 16:7 crop for banners. Avoid text embedded in photos; use real HTML text and buttons so they remain readable on mobile.
